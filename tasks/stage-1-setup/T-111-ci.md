## Goal

Every pull request is checked automatically.

## Steps

- Add a GitHub Actions workflow (or Netlify build plugin) running lint, `nuxi typecheck`, Vitest and convex-test.
- Add a Playwright job (can be enabled once Stage 2 e2e tests exist).
- Make checks required on `main`.

## Files

- `.github/workflows/ci.yml`

## Acceptance criteria

- [ ] A failing test blocks merge.
- [ ] CI runs in under ~10 minutes.
