## Goal

Every pull request is checked automatically.

## Steps

- Add a GitHub Actions workflow (or Netlify build plugin) running lint, `nuxi typecheck`, Vitest and convex-test.
- Add a Playwright job (can be enabled once Stage 2 e2e tests exist).
- Make checks required on `main`.

## Files

- `.github/workflows/ci.yml`

## Acceptance criteria

- [ ] A failing test blocks merge.
- [ ] CI runs in under ~10 minutes.

## Notes

- Workflow: `.github/workflows/ci.yml`. Job `checks` (Node from `.nvmrc`, npm cache, 10 min timeout) runs `npm ci`, `lint`, `format:check`, `typecheck`, `npm test` (unit + convex-test). Superseded runs on the same PR/ref are cancelled. Job `e2e` (Playwright) is present but disabled with `if: false`; delete that line once Stage 2 adds specs under `tests/e2e`.

- The repo has no git remote yet, so both acceptance criteria are unverified until it is on GitHub and a PR has run.

### Branch protection (do once the repo is on GitHub, after the first CI run on a PR)

1. Settings > Branches > Add branch protection rule (or Rulesets > New branch ruleset) for `main`.
2. Enable "Require a pull request before merging".
3. Enable "Require status checks to pass before merging" and add the check named `checks` (it only appears in the search box after it has run once). Enable "Require branches to be up to date before merging".
4. Optionally enable "Do not allow bypassing the above settings".
5. When Playwright is enabled, also add `e2e` as a required check.
6. Verify: open a PR with a deliberately failing test and confirm the merge button is blocked, and that the run finishes in under ~10 minutes.
